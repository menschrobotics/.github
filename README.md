# Mensch Robotics

**Building human-centric Physical AI and modular semi-humanoid robotics for education, research, and real-world deployment.**

Mensch Robotics Pvt. Ltd. is a deep-tech robotics company developing accessible, open-architecture robotic platforms and embodied AI systems. Backed by the **Kerala Startup Mission (KSUM)**, **IHFC (Technology Innovation Hub of IIT Delhi)**, and **Startup India**, we bridge the gap between academic robotics research and real-world human-robot interaction.

---

### Getting Started & Contributing

We welcome contributions from robotics engineers, researchers, and students:

1. **Explore our repositories** below to find ROS 2 packages, hardware interfaces, and example demos.
2. **Found a bug or have a feature request?** Open an issue in the relevant repository with clear reproduction steps.
3. **Want to contribute code?** Fork the repository, create a feature branch, and submit a Pull Request following the repository's `CONTRIBUTING.md` guidelines.
